After doing the test, it seems that my decoder cannot properly restore the image from the compressed binary file.

I will need to check this.

After some simple test, I first found that the image cannot be restored at all, it will simply just return all zero images.

Then I found that in the decoder, this line will create a list of list instead of list.

for example:
```python
MT_lst = []
new_lst = np.full((1,3), 2).tolist()
>>> [[2, 2, 2]]
MT_lst.extend(new_lst)
>>> [[2, 2, 2]]
```

This would mean that the length of this new list is 1 instead of expected 3, this would cause the problem when we verify if we have finished this row.

After fixing this, I ran the script again and still failed. Then I found that the decoded image is 1 less row than expected.

And then I found the if-else tree in this one is not correct:

This would mean that the outcome would be one of the 3:

+ all zeros, increment counting
+ not all zeros, but the all_zero_cnt is not zero
+ other case

But the actual logic should only be 1 of 2:

+ all zeros, increment counting
+ not all zeros

if its not all zeros, it would do writing for the all_zero_cnt before encode the row if it is not 0, otherwise, still encode the code.

And the logic now is correct and I have managed to reproduce the uncompressed image.
